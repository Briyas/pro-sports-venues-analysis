## 📌 Project Overview

This project explores the geographical distribution, venue metadata, and team aesthetics for major North American professional sports leagues (**NBA, NFL, MLB, NHL**). 

By analyzing venue locations, capacity, geographical coordinates, and visual branding (team logos and colors), this repository provides insights into spatial sports analytics and data visualization.

---

## 📊 About Dataset

A comprehensive dataset containing all active venues across the major four North American sports leagues.

### 🔍 Features Included:
- **League & Team Information:** Team names, division, league affiliation (NBA, NFL, MLB, NHL).
- **Venue Details:** Stadium/Arena name, city, state, country, open year, capacity.
- **Geospatial Data:** Exact latitude and longitude coordinates for mapping and distance calculations.
- **Branding Assets:** High-resolution team logos, primary colors, and secondary HEX color codes.

> **Dataset Source:**  
> 🔗 [Kaggle - Pro Sports Venues (NBA, NFL, MLB, NHL)](https://www.kaggle.com/datasets/peteyy/pro-sports-venues-nba-nfl-mlb-nhl?select=pro_venues_clean_final_2.0.csv)
